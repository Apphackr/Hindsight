HINDSIGHT — travel with hindsight
=================================

Your travel app: trips, AI plans, saved places, bookings, spend, checklists,
logged places with photos, wishlist and profile. Everything is stored on your phone.


1. PUT IT ONLINE (once, about 5 minutes, easiest on a computer)
   - Go to https://app.netlify.com/drop and sign up free.
   - Drag this whole "hindsight" folder onto the page.
   - Netlify gives you a web address like https://something.netlify.app.
     You can rename it under Site configuration > Change site name.

2. INSTALL IT ON YOUR PHONE
   - iPhone: open the address in Safari > Share > Add to Home Screen.
   - Android: open it in Chrome > menu (⋮) > Install app.
   - Open it from the home-screen icon and set it up there. On iPhone, the
     home-screen app and the Safari tab keep separate data.

3. SWITCH ON THE AI
   - Go to https://console.anthropic.com/settings/keys, create an API key,
     add some credit and set a monthly spend limit.
   - Paste the key into Hindsight > Settings and tap "Test the connection".
   - A full trip plan usually costs a few pence. "Look things up live" adds
     about 1p per web search. You can switch it off in Settings.

4. BACK UP NOW AND THEN
   - Settings > Back up saves one file with everything, photos included
     (not your API key). Settings > Restore loads it on any phone.

Updating: if you get a new version of these files, drag the folder onto
your Netlify site's Deploys page. Your data stays on your phone.

Already running the older "Wayfarer" version? Upload this folder to the SAME
Netlify site (Deploys page) and your trips carry over. If you set up a new
site or address instead, back up first in the old app, then Restore in the new one.
